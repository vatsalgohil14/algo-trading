# Algo Trading

An intraday trading system for NSE stocks, written in Rust, with QuestDB for data and Dhan as the broker.

**[Read the documentation](https://vatsalgohil14.github.io/algo-trading/)**

The system is built and tested on simulated data only. It has not run on real market data or placed a real order, so nothing here shows that it makes money. This is an engineering project, not investment advice.
