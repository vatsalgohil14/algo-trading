# Algo Trading

A monthly momentum rotation for NSE stocks, written in Rust, with QuestDB for data and Dhan for market data.

**[Read the documentation](https://vatsalgohil14.github.io/algo-trading/)**

The strategy has passed a 2010–2026 backtest and is being paper traded from 20 November 2026. It places no real orders. Past results don't promise future returns, and this is not investment advice.
